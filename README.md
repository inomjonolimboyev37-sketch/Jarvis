# Jarvis

O‘zbek tilidagi shaxsiy yordamchi uchun yengil, moslashuvchan web-interfeys. Hech qanday build vositasi yoki kutubxona talab qilmaydi.

## Ishga tushirish

`index.html` faylini brauzerda oching yoki GitHub Pages orqali joylashtiring.

## Imkoniyatlar

- O‘zbek tilidagi suhbat interfeysi va tezkor savollar
- Mahalliy vaqt, sana, salomlashish va sodda arifmetik hisob-kitoblar
- Brauzer qo‘llab-quvvatlasa, mikrofon orqali ovozli kiritish
- Mobil qurilmalarga mos qorong‘i dizayn
- Suhbat brauzer ichida ishlaydi; tashqi xizmatga so‘rov yuborilmaydi

## AI xizmatini ulash

Hozirgi javoblar demo qoidalar asosida ishlaydi. Haqiqiy AI modelini ulash uchun API kalitini brauzer kodiga joylamang. Kalitni server tomonda saqlaydigan backend endpoint yarating va front-enddan o‘sha endpointga murojaat qiling.
